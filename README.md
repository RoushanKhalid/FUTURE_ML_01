# Retail Sales Forecasting Project

## Overview
This project develops a machine learning solution to predict future retail sales using historical transaction data. Initially implemented with Facebook's Prophet for time-series analysis, the model was later enhanced using XGBoost with feature engineering to improve accuracy.

## Key Features
- Time-series analysis with Prophet
- Machine learning implementation with XGBoost
- Feature engineering 
- Performance comparison between models
- Interactive visualizations of forecasts

## Technologies Used
- Python 
- Pandas (Data manipulation)
- Prophet (Time-series forecasting)
- XGBoost (Gradient boosting)
- Matplotlib/Seaborn (Visualization)
- Scikit-learn (Model evaluation)

## Dataset
The dataset contains:
- Daily sales records
- Product categories
- Pricing information
- Customer demographics
